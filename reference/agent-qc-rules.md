# 成片 QC 协议（原创片：对照分镜表与本套风格规格，不是对照原片）

> <项目根> 替换为工作目录绝对路径；vN 为版本号；Cn 为章号；`<n>` / `<id>` 是本片选定的风格（`config.style`）。

输入：成片逐帧 `<项目根>/fin_frames/f_%04d.jpg`（1 起）、缩略总表 `<项目根>/renders/sheet_vN.html`、`<项目根>/分镜表.md`（帧区间/节拍/画面意图）、`<项目根>/script/timeline.md`（字幕块帧号）、skill 的 **`reference/common-rules.md`（量化判据）+ `reference/styles/<n>-<id>.md`（本套 S1–S8，尤其 S8 红线）** + `reference/motion-vocabulary.md`、`<项目根>/research/调研.md`、各组 `<项目根>/src/shots/Gn/BUILD_NOTES.md`（已知降级项，不重复报）。
输出：`<项目根>/qc/qc_vN_Cn.md`，**边查边 append**。每条：`| 严重度 高/中/低 | 镜头 | 帧 | 现象 | 判据 | 建议修法 |`。

> **判据来源要写清**：每条问题后面注明是按 `common-rules.md` 的哪一节、还是按本套 `styles/<n>-<id>.md` 的哪一槽。不要把某一套的规格当成通用标准——**第 1 套的「青色」「近黑底」在第 4 套就是缺陷**。
>
> 英文片（`config.ts` 的 `lang: 'en'`）另加两条：字幕折成两行（说明该块超 48 字符预算，已压进内容区）→ 中；进度条章名或章节卡标题被自动缩字号到发虚 → 低，回去把章名改短。

## 看什么（按优先级）
1. **可读性/遮挡**：任何文字被字幕带（y637–690）、进度条（y687–720）、HUD（y28–100）、流程轨（有轨的章 y112–160，见分镜表「常驻层」）遮住或紧贴（<10px）；文字溢出画布；字号低于本套 S3 的 `minPx`（深底 22 / 浅底 24）；**文字与它所在底的对比度不足**（浅底白字、深底深字）；灰字在雾底/实拍上不可读。
2. **节拍**：关键元素出现帧 vs 对应字幕块起始帧（timeline.md）：晚 >3 帧或早 >6 帧记中；整句没有对应画面变化记高。检查方法：看字幕块起始帧 −6、0、+3、+8 四张帧。
3. **事实/拼写**：画面英文与数字逐个核对调研文档；错字/繁简混用/术语不一致（同一概念两组写法不同）记中。
4. **风格一致（对照本套 S2 / S3 / S4 / S6，逐项）**：
   - **S2 调色板**：只出现本套定义的几个颜色角色，没有第五种；角色分工没有互换。判法用 `frame_metrics.py --style <id>` 的碎片统计，再回帧确认。
   - **S3 字体**：中文字族与字重、英文技术词是否该用斜体（第 3、4、5 套规定不上 Exo 2 / Orbitron，出现了就是中）、压窄系数。
   - **S4 图元语法**：描边宽度（`sw`）、圆角（`radius`）、填充方式（outline / solid / glass）是否与该套一致。
   - **S6 覆盖层**：**浅底两套（compare / cards）的字幕必须是深字浅边**，进度条分隔线与章名已转深；深底套为白字深边。这一条错了整片贴纸感。
   - glitch 入场缺失或过度（>12 帧闪烁）。
   - **幕底被盖掉**：大面积不透明纯色盖住本套的幕底（点阵 / 星点 / 渐变 / 实拍）——判「幕底还在不在」，不是判「是不是黑色」。
5. **衔接**：相邻镜头交界帧（分镜表每行 from/to）：前后两帧是否有元素突然消失/跳位/重复绘制；组界（G1|G2 …）尤其看 HUD/流程轨与内容是否重叠；**章界**（章节卡前后各 3 帧 + 章首镜头首 30 帧）：章首镜头是不是完全另起的新画面、分镜表「章界清单」写的承接元素有没有做到 → 中；顺带核对章首解说有没有回指上一章（从零起头或只报幕 → 低，报主会话，改词代价见第 11 项）；章节卡前是否有内容残留；<90 帧却带完整入场 + 离场的碎镜头 → 低（应并入相邻镜头当节拍）。
6. **动画质量**：抽每镜头 3 处连续 3 帧（入场中段/中间/离场中段）看是否有抖动、方向反、缓动生硬（线性大位移）、元素从画外"闪现"（首帧就在终点）、kf 首值陷阱（镜头一开始就停在中段状态）。
7. **性能痕迹**：模糊/发光过度导致的灰雾、渐变色带、文本边缘锯齿。**注意本套是否允许模糊**：第 1 套的磨砂玻璃必须模糊，第 5 套出现任何模糊都是缺陷。
8. **构图与光**（`common-rules.md §5` 的结构判据 + 本套 S5 的光形态）：先跑 `python3 <项目根>/scripts/frame_metrics.py --style <id> --frames <项目根>/fin_frames --storyboard <项目根>/分镜表.md --out <项目根>/qc/frame_metrics_vN.md`，把本章镜头的标记逐条并入报告并看帧确认：
   - 内容区主体尺度 <110px 且无大面积光活动持续 >45 帧 → 中（<80px → 高；扫光 / 光线阶段不算空场）；主体中位尺度 <170 → 低。
   - **高光时刻镜头主角区无光斑 → 中**。注意「光」按本套 S5 判：第 4 套是彩色投影、第 5 套是硬投影，`frame_metrics` 的柔光面积读数为 0 是正常的，此时看**投影有没有**，不能直接判无光。
   - 一帧**主色族碎片**（色相距本套 `primary` ±25°）≥8 → 低。**不要按「紫色」判**：第 1 套的主色是青，第 3 套是暖金。
   - 背景散落小图形 ≥10 → 中（点云 / 方点阵列会误触发，看帧确认是整齐矩阵还是随机碎屑）。
   - **扫光白名单外的镜头出现三轮扫光 / 舞台光线 / 幽灵轮廓 → 中**（全片 ≤2 处）。**第 3/4/5 套只要出现这三样就是高**——它们的 S8 明确禁止。
9. **持续动作与落位停留**（`common-rules.md §7`）：先跑 `python3 <项目根>/scripts/motion_check.py --frames <项目根>/fin_frames`。最长静止 >3 s 的镜头看帧：全分辩率变化像素 <800 = 真静 → 中（给出动词对应的动作，**不要建议加漂浮 / 呼吸**）；800–2500 = 小面积动作 → 低（建议加大幅度）。末拍稳定期 <30 帧（末拍元素落位到离场起点）→ 中：建议推后离场 / 前挂末拍元素 / 并入相邻镜头，不是加动作。运镜在离场前 30 帧内还没结束 → 中。静止占比只作参考，不单独定缺陷。
10. **运镜**：对照分镜表「运镜清单」逐条看首 / 中 / 末帧：推近是否绕主角、是否 30–45 帧 easeInOut（线性或 <15 帧记中）、运镜期间有没有 glitch 或错峰入场（记中）、HUD / 流程轨 / 字幕是否被带着动（记高）；一章少于 3 次运镜记低。
11. **导航标签**：进度条章名（每章一个词组）与 HUD 小节名——只看这几个词，能不能说出该段讲什么？出现比喻、评价句、悬念词（反例 `感觉还行` / `两把尺子`）→ 低，直接给出改名建议。**改名很便宜**：章名只在 `narration.txt` 的 `# CHAPTER n 名` 行、HUD 词只在 `config.ts` 的 `hud[].text`，都不影响帧号与配音。
12. **本套 S8 红线逐条过**（最容易被漏、也最容易被判成「个人偏好」的一项）：把 `styles/<n>-<id>.md` 的 S8 列表和 `styles.ts` 的 `forbid[]` 摊开，一条一条在全片找反例。每条都是一个**明确的缺陷**，不要写成「建议」。例：第 1 套找到紫色、第 4 套找到发光、第 5 套找到圆角、第 2 套把青用在卡片上、第 3 套用了现有视频的帧——这些都要记**高**，并且直接指出帧号。

## 怎么看
- 先看 `sheet_vN.html` 通读全片一遍（每 60 帧一张），列出可疑镜头；再对每个镜头按分镜表逐"节拍帧"看单帧；最后按 §5/§6 看连续帧。
- 用 Read 看图；需要量化（bbox/颜色/亮度）用 Python PIL（亮度求和用 int32，int16 会溢出）。不要修改任何源码。
- 闪烁合规（终检）：对每个镜头元素入场帧做 f0…f0+12 亮度曲线，0/0.5/1 跳变 = 闪烁；命中数必须等于白名单条数。
- 每个镜头至少给出一行结论（"OK"也要写），保证覆盖。

## 严重度
- 高：文字不可读/遮挡、整句无画面、事实错误、组件缺失（分镜表有而画面没有）、幕底被盖掉、空场（主体 <80px 持续 >45 帧）、运镜带动 HUD / 字幕、**违反本套 S8 红线**（第 3/4/5 套出现扫光也在此列）。
- 中：节拍偏差、风格不一致（S2/S3/S4/S6 任一项不符）、衔接跳变、拼写、主体 <110px 持续 >45 帧、高光时刻主角无光、背景碎屑、运镜生硬或与 glitch 重叠、最长静止 >3 s、末拍稳定期 <30 帧（落位即切）、运镜进末拍。
- 低：微调（间距/对齐/亮度）、主色族碎片、可选优化。

> 判定时如果拿不准「这算风格偏好还是缺陷」，回本套 S8：**写在红线里的就是缺陷，没写的就不是**。不要用另一套的规格来判这一套。
