# 2 AI 搜索引用链路（citation）

> 令牌在 `template/src/styles.ts` 的 `id: 'citation'`。本文件是它的**规格**。
> 本套**不出图**（`useImageGen: false`），全部图形由代码绘制。

**气质**：靛蓝点阵底上一条看得见的理解链路——中央是 AI 回答界面，引线连向网页、文档与引用。紫为主，青只走引线。
**适配**：内容结构优化、品牌知识建设、GEO 机制；主题在讲信源、引用、知识库、被写进答案的路径。**主题提到「搜索」但核心是信源与引用时用这套，不要因为「搜索」二字跳去大屏。**

## S1 底

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | `#0D0B1F` 靛蓝 | 比大屏暖一点、偏紫，亮度低于 20 |
| 幕底 | `dots` 点阵波 | 点距 48（960×540 设计坐标等比放大）、半径 2–2.7px、点色 `#3B3470`、底色 `#0D0B1F` |
| 渐变末端 | `#1B1440` | 只用于底部雾感过渡，不加第二处光 |
| 左侧空区 | **无** | 本套标题居中或压在内容上方，不设空区 |

- 点阵是**屏幕空间静态纹理，不跟运镜**；斜向波前约 9.3 s 扫过一遍。
- ⚠️ 点阵会抬亮全屏基底：本套的「空区」下限**不是** 20，而是 **22**（`frame_metrics.py` 的 `SOFT_LO` 在 `backdrop == 'dots' 且非浅底` 时取 22）。按 20 判会把整片判成亮场。
- `BG_Gn` 的 `stars:'none'` 区间同样关掉点阵，用于需要绝对静场的镜头。

## S2 调色板（四个角色，紫与青分工不得互换）

| 角色 | 值 | 用在 |
|---|---|---|
| 主体紫 | `#8B5CF6`（深 `#5B21B6`、亮 `#B49BFF`、淡 `#E9E3FF`） | 当前重点、答案块、激活节点 |
| 引线青 | `#22D3EE` | **只给引线、箭头、链路流动光点** |
| 幻觉玫红 | `#F43F5E` | 幻觉 / 不可信 / 错误引用，必带双层柔光 |
| 结构与字 | 字 `#F1F5F9`；结构线 `#CBD5E1`；灰 `#6B7280`；网格 `#2E2850` | 标题、卡片描边、网格 |

- **紫 = 内容归属，青 = 传导关系**。把青用在卡片上、或把紫用在引线上，本套的语义就塌了——这是本套最容易犯的错。
- 一帧里紫色大面积**不超过一处**；引线可以有多条，但要一眼看出它们**汇向**哪一个主体。
- `#2A2440`（`dimMid`）是「未激活卡」的填充色，比画布只亮一档。
- 绿 `#34D399` 只用于「被正确引用 / 命中」的勾，不用于装饰。

## S3 字体

- 中文 Noto Sans SC 900，压窄 **.85**。
- 英文技术词 Exo 2 斜体，紫 `#A78BFA`（`primaryTech`）——**不是**青，青色在本套专供引线。
- 数字 Orbitron（引用条数、排名位次、信源数量都是科技感指标）。
- 最小 22px。

## S4 图元语法

核心语法是**「节点 + 引线」**，不是卡片阵列。

- 节点三类：中央回答块（主角）、信源卡（网页 / 文档 / 知识库）、引用条（编号 + 出处行）。
- **玻璃卡**是节点外壳（`fillMode: 'glass'`，圆角 12、描边 2px）：必须能看见卡片后面的点阵背景，实色板不算。
- 引线：2px 青线，自节点边缘**长出**（draw-on 16–28 帧），末端小箭头；汇入点时收成一束，不要交叉成网。
- 引线上跑一个光点（6px 圆点 + 青光），沿路径匀速，这是本套的**持续动词动作**（公共规则 §7）。
- 引用条是横向细条（高 44–56），左侧编号用 Orbitron，右侧出处行用 22px 灰字。引用条**不发光**，只有「当前被引用」那一条可以 `GLOW_HERO_S`。

## S5 光

- 主角（中央回答块）常亮：紫色双层柔光（`GLOW_HERO`，12px/42px）。
- 当前重点：≤1 处 `GLOW_HERO_S`（24px/8px）。
- 引线是**自发光**而非被照亮：青线本身带 `0 0 8px` 青光，不加氛围光。
- 幻觉：玫红双层柔光 `0 0 60px 20px`，只罩在那一段错误内容上。
- **高光时刻是 `sweep` 型**：三轮扫光 + 舞台光线 + 主角大字轮廓预示。
  - 公共上限是全片 ≤2 处；**本套自己收到 1 处**，只给「AI 是怎么选中你的」这个核心概念首次登场。
  - 扫光的那一帧不叠加引线流动，否则两种运动打架。

## S7 素材：全代码绘制

本套 `useImageGen: false`、`spec: null`。**不出背景图，不出物件图。**

- 背景就是 S1 的点阵波（`DotFieldBg`）+ 底部雾感渐变，没有第二层图。
- 所有节点、引线、引用条、图标由 `ui.tsx` / `fx.tsx` 的图元拼，图标若需要就用**线稿 SVG 内联**（2px 青 `#22D3EE` 或紫，与引线同宽），不要用生图得到的位图。
- 因此本套**不需要**「出图前核对」那一套（背景 prompt、物件 prompt、合成规则）。需要核对的是引线与节点的接线关系：
  - 每条引线的起点在节点边缘、终点有箭头或收束点；
  - 引线不穿过文字，不压字幕带（y637 以下）；
  - 引线数量 ≤ 该镜头信源卡数量，不为了「看起来复杂」多画线。
- 若某镜头确实需要实拍质感，改选第 3 套（growth），不要在**本套里混入位图**。

### 帧号

镜头表帧号从 1 起（`useCurrentFrame()+1`）；静帧用 `remotion still --frame=N-1`。

## S8 红线

1. **青不给卡片、紫不给引线**——两色分工是本套的定义，互换即失效。
2. 禁止把紫色撒在配角上：一帧紫光只给当前重点一处。
3. 禁止用实色板冒充玻璃卡：卡片后面必须看得见点阵。
4. 禁止鲜红；幻觉 / 不可信只用玫红 `#F43F5E`，且带双层柔光。
5. 禁止扫光超过 1 处（公共上限 2 处，本套自己收到 1 处）。
6. 禁止在引线上叠第二套运动（扫光期不跑流动光点）。
