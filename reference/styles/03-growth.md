# 3 企业增长故事（growth）

> 令牌在 `template/src/styles.ts` 的 `id: 'growth'`。本文件是它的**规格**。
> 本套**不出图**（`useImageGen: false`）：实拍素材来自免版权库，不是生图。

**气质**：黄昏城市与办公室实拍打底，暖金配深蓝；分析图形只作点缀，不铺满发光特效。
**适配**：B2B 品牌、解决方案、客户案例；主题在讲获客、转化、从曝光到咨询、客户为什么不来。**增长数字只用有出处的数。**

---

## S1 底

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | `#0B1426` 深蓝 | 实拍未覆盖处的兜底色 |
| 幕底 | `footage` 实拍 | 黄昏城市天际线 / 夜间办公室 / 会议室过手 |
| 渐变末端 | `#122036` | 实拍压暗后的过渡色 |
| 左侧空区 | **无** | 标题压在实拍上，靠压暗与投影取得可读性 |

- 实拍素材是**背景**，不是内容。任何要读的字、要数的数、要比较的块，都由代码画在实拍**上面**。
- 实拍拍的是环境：远景城市、窗边逆光、走道人群的虚焦背影。**不拍**人脸特写、不拍可辨识品牌标识、不拍屏幕内容。
- 每段实拍必须**压暗**（`opacity` 或黑色叠层 .35–.55）后才允许放文字；压暗后仍要能看出「这是黄昏、这是城市」。
- 一段实拍覆盖 2–4 个章节；换素材即换章节，不要在章内跳素材。

## S2 调色板（暖金为主，深蓝为配，仅两色有温度）

| 角色 | 值 | 用在 |
|---|---|---|
| 暖金 | `#F5B544`（亮 `#FFD07A`、深 `#B4771F`、淡 `#FFF2DC`） | 增长、正向、当前重点、指标数字 |
| 深蓝 | `#3B82F6` | 第二重点、「另一侧」、对比项、图表基线 |
| 结构白 | `rgba(255,255,255,.60)` 线 / `#FFFFFF` 字 | 卡片描边、箭头、标题 |
| 灰 | `#9CA3AF` | 次要文字、未激活项 |
| 警示红 | `#DC2626` | 真正的亏损 / 流失 / 错误，**不是**装饰 |

- 暖金是**「我们带来的」**，深蓝是**「环境 / 客户 / 现状」**。增长曲线、转化箭头、达标勾用金；客户侧数据、行业均值用蓝。
- 一帧里金色面积 ≤1/4 屏；金色一多就变成促销海报。
- 绿色 `#22C55E` 只用于勾选与「通过」，不做数据系列色。

## S3 字体

- 中文 Noto Sans SC 900，压窄 **.82**（比科技两套略松，商务题材需要更端正）。
- 英文与数字**全用 Noto**，不上 Exo 2、不上 Orbitron——宽体科技字会立刻破坏商务调性。`numFamily: 'cjk'`。
- 最小 **24px**（实拍底噪点比纯色底多，字号要抬一档）。

## S4 图元语法

- **实描边 + 投影**，`fillMode: 'outline'`、`radius: 4`（近直角，商务感）、`lightMode: 'shadow'`。
- 卡片：透明填充 + 1.5–2px 结构白边，靠 `0 2px 6px rgba(0,0,0,.55)` 从实拍上浮起来。**不填灰、不填黑**——填了就成了贴纸。
- 数字是主角：增长百分比、客户数、成本降幅用 96–150px 暖金；正负号与百分号同字号（不要缩小）。
- 箭头：2px 实线 + 实心三角头，沿实拍的对角线走向（右上为增长，右下为下滑），不做弯钩、不做虚线流动。
- 折线 / 柱图：只有坐标轴与数据线，**不画网格满屏**；一条线到顶，配一个端点圆点 + 数值标签。

## S5 光

本套是五套里**唯一以投影代替发光**的深底套。

- 分层靠 `drop-shadow`：卡片 `0 2px 6px`、数字 `0 4px 14px rgba(0,0,0,.6)`。
- 主角（金色大数字）可带**一层**暖金柔光 `0 0 16px 4px rgba(245,181,68,.28)` + `0 0 48px 16px`——这是本套允许的唯一发光，且只在 h 光时刻用。
- 当前重点：`GLOW_HERO_S` 暖金 26px/10px。
- **高光时刻是 `headline` 型**：一句断言式大字压在压暗的实拍上（+ 金色细分隔线 + 小字注脚），不要扫光、不要舞台光线、不要白闪。
- 实拍本身的光（夕阳、窗光）就是氛围，**不要再用代码加第二处光**。

## S7 素材：实拍规范（本套专属）

`useImageGen: false`。素材是**下载的免版权视频片段**，不是生图。

### 来源与登记

- 只用明确标注可商用免版权的素材（Pexels / Pixabay / Coverr 等），逐条记进项目 `MANIFEST.md`：文件名、来源 URL、作者、许可、下载日期。
- **禁止使用任何现有视频的帧**（包括自家旧片、客户片、竞品片）——版权与「二次剪辑」都说不清。
- 素材命名 `plates/city-dusk.mp4` / `plates/office-night.mp4` / `plates/meeting-walk.mp4`，放 `public/assets/<slug>/plates/`。

### 选片判据（下载前看，别下回来再挑）

- 16:9 或可裁到 16:9，分辨率 ≥1920×1080；帧率 24/25/30 均可，**同一片内统一**。
- 画面里**没有**：可辨识人脸、公司标识、屏幕上的可读文字、字幕、水印。
- 运镜是慢推、慢摇或固定；**不要**快切、手持抖动、明显变焦。
- 色调偏暗（黄昏 / 夜 / 阴天）优于大晴天；亮片压暗后会发灰。
- 一段 ≥8 s，够裁 2–4 个章节。

### 用在片子里

- 每段实拍**只用一个连续区间**，不做同段多次跳回。
- 实拍之间用 6–8 帧黑场或金色闪白过渡（**闪白只用 3 帧**，公共规则的事件闪上限）。
- 实拍上方压暗层：`rgba(11,20,38,.45)` 起，按素材亮度调；压完内容区（x60–1220 / y110–620）平均亮度要落在 40–110，太亮字读不清、太暗看不出实拍。
- 实拍**不参与运镜**：`CameraRig` 只作用于内容层，实拍固定在背景层（否则实拍会露边）。

### 何时出成片

用户看静帧时只出静帧。静帧要覆盖：压暗最亮的一格、金色大字那一格、实拍切换那一格。

### 出静帧前核对

- 每个实拍段都进了 `MANIFEST.md`，来源可点开。
- 内容区亮度 40–110；标题与大字在实拍最亮的区域上仍可读（截图看像素，不靠肉眼估）。
- 实拍边缘没有露出画布底色（缩放 ≥1.02 覆盖）。
- 金色面积 ≤1/4 屏；全片没有第二处代码光。
- 数字与百分比都有出处，虚拟业绩已在画面上标「示意」。

## S8 红线

1. 禁止满屏发光特效（本套靠实拍氛围 + 投影分层）。
2. 禁止紫色（紫色属于第 2 套，本套是暖金 + 深蓝）。
3. 禁止用 Orbitron / Exo 2 等科技字做数字与英文（与商务调性冲突）。
4. 禁止虚构增长曲线的形状去暗示真实业绩；数据必须有出处，示意数据必须标「示意」。
5. 禁止使用任何现有视频的帧；实拍素材必须登记 `MANIFEST.md`。
6. 禁止在实拍上再叠代码光（夕阳与窗光已经是光）。
