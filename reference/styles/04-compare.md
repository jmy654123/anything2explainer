# 4 SEO 与 GEO 对比（compare）

> 令牌在 `template/src/styles.ts` 的 `id: 'compare'`。本文件是它的**规格**。
> **浅底第一套**：字幕、面板、进度条的语义全部反转，见下面各槽。

**气质**：左右分屏，白与浅紫底，左蓝右紫各管一侧；实描边 + 柔和投影，**不用发光**。
**适配**：解释概念、纠正误区、系列栏目；主题在讲两种做法的区别、谁过时了、怎么一起布局。

## S1 底

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | `#FFFFFF` 纯白 | 浅底，`IS_LIGHT = true` |
| 幕底 | `gradient` | 上白 `#FFFFFF` → 下浅紫 `#F3F0FF`，是**一层薄雾**，不是光 |
| 中线 | x = 640，1.5px `#E2E8F0` | 两侧的物理分界；可断可续，但位置不动 |
| 左侧空区 | **无** | 本套左右各半，标题居中压在中线上方 |

⚠️ **浅底的反转是自动的**（`theme.ts` 的 `IS_LIGHT` 分支），你必须知道的四条：
1. `PANEL` 从黑变白（卡片底填 `#FFFFFF`）；
2. 字幕改为**深字白边**（`#0F172A` + `#FFFFFF` 描边），不是白字黑边；
3. 进度条分隔线转深（`rgba(15,23,42,.12)`）；
4. 片尾压黑改为**压向画布底色**（白），不是压黑。

## S2 调色板（左右两色是语义，不得互换）

| 角色 | 值 | 用在 |
|---|---|---|
| 左 / 甲侧 蓝 | `#1D4ED8`（亮 `#3B82F6`、深 `#1E3A8A`、淡 `#DBEAFE`） | 左侧标签、左栏描边、左侧箭头 |
| 右 / 乙侧 紫 | `#7C3AED` | 右侧标签、右栏描边、右侧箭头 |
| 结构墨 | 字与线 `#0F172A`；灰 `#64748B`；浅灰块 `#E2E8F0`；网格 `#CBD5E1` | 标题、正文、轴线 |
| 否定 / 肯定 | `#DC2626` / `#16A34A` | 「不行」的叉、「可以」的勾 |

- **左蓝右紫是本套的定义**。左右换色 = 换了语义，不是换了配色。
- 两色的**饱和度与明度必须同级**（都在 600 档）。一侧明显更鲜艳，观众会读成「这一侧更重要」。
- 中间的中性符号（`vs` / `≈` / `+` / `→`）用墨色 `#0F172A`，**不要**用第三色。
- 灰色 `#64748B` 只给说明字与「两侧都有」的公共项。

## S3 字体

- 中文 Noto Sans SC **800**（浅底上 900 会糊成一团实心，800 更透气），**不压窄**（`squeeze: 1`，浅底可读性优先）。
- 英文与数字用 Noto，`numFamily: 'cjk'`。
- 最小 **24px**（浅底对比度低于深底 + 白字，字号要抬一档）。

## S4 图元语法

核心语法是**「中线分屏 + 对称对照」**。

- 两侧各一个内容栏：x 60–600 / x 680–1220，**同高同宽**，上下边对齐到同一 y。
- 每侧顶部一个标签 Pill（高 52、圆角 6、实描边 2px，文字用本侧色），下挂该侧要点 3–4 条。
- 卡片 `fillMode: 'outline'`、`radius: 6`、描边 2px。**填充必须是白或淡色**，不能透出幕底渐变（浅底上透明卡会显脏）。
- 箭头：2px 实线 + 实心三角头，长度 ≤120，只在本侧内部走；**不跨中线**。要表达「合起来」时，两侧箭头在中线下方汇成一条向上箭头，用墨色。
- 勾 / 叉用 `Check` / `Cross` draw-on，尺寸 32–40，放在每条要点的行首。
- 对照行支持「逐行配对」：左第 i 行与右第 i 行同 y，行间用一条极浅的分隔线（`#E2E8F0` 1px）连过去，穿过中线——**这是本套唯一允许穿中线的元素**。

## S5 光

- **全片不用发光**。`lightMode: 'shadow'`。
- 分层只有一种手段：`0 8px 24px rgba(15,23,42,.14)` + `0 2px 6px rgba(15,23,42,.10)`。
- 当前重点：`0 4px 16px rgba(29,78,216,.24)`——是**彩色投影**，不是彩色发光。这是本套「有强调但不发光」的关键手法。
- **高光时刻是 `split` 型**：中线亮起（一条 1.5px 线从中间向两端长出）+ 两侧同时登场 + 中央一个墨色 `vs`。不要扫光、不要白闪、不要舞台光线。
- `GLOW_TEXT` 与 `BLOOM` 在本套为 `none`；白字上再加发光直接不可读。

## S7 素材：全代码绘制

`useImageGen: false`、`spec: null`。浅底上任何位图都会带自己的白平衡与阴影，和纯白画布拼不齐。

- 背景就是 S1 的白→浅紫渐变，不叠图、不加噪点。
- 需要「实物」时用**扁平几何**表达（手机用圆角矩形 + 3 条线、文档用折角矩形），不要生图、不要 3D 图标、不要渐变球。
- 图标线宽统一 2px，颜色取本侧色（左蓝右紫），**不给图标加投影**——图标已经够小，投影会糊。

### 出静帧前核对

- 两侧内容栏**同高同宽**，上下边在同一 y；中线位置在 640±1。
- 左右两色的饱和度、明度同级；没有第三色出现。
- 字幕是深字白边，不是白字黑边（这是浅底最容易漏的一条）。
- 白卡不透出幕底渐变（放大看卡片内部是纯白，不是淡淡的紫）。
- 全片找不到 glow：把静帧截图调亮 30%，发光会先暴露成一圈晕。
- 勾与叉都完整 draw-on 到位，没有半截图形。

## S8 红线

1. **禁止发光与柔光**（一有 glow 就变成科技片）。唯一的「光」是彩色投影。
2. 禁止白字（浅底上不可读）；字幕必须是深字白边。
3. 禁止左右两侧混用同一种色——左蓝右紫是语义，不能互换、不能对调、不能只留一侧。
4. 禁止中线两侧不同高不同宽。
5. 禁止扫光 / 白闪 / 舞台光线作为高光时刻。
6. 禁止在浅底上叠位图背景或 3D 图标。
