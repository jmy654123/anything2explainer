# 5 极简动态图形（cards）

> 令牌在 `template/src/styles.ts` 的 `id: 'cards'`。本文件是它的**规格**。
> **浅底第二套**：与第 4 套共用浅底反转（第 4 套 S1 的四条），但视觉语法完全相反——第 4 套是描边，本套是实色块。

**气质**：米白底、粗几何实色块、电光蓝配橙，硬投影 offset 8px；**没有圆角、没有渐变、没有发光**。
**适配**：清单、日更、批量生产、一个知识点；主题是三件事、逐项检查、知识矩阵。**对不上其他四套时也用这套。**

---

## S1 底

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | `#FAF9F7` 米白 | 不是纯白——纯白配硬投影会显脏，米白给色块一个落点 |
| 幕底 | `gradient` | 上 `#FAF9F7` → 下 `#F2F0EC`，极浅，几乎看不出 |
| 网格 | **无** | 本套不用网格线、不用点阵；`grid` 令牌虽为 `#111111` 但只在必要时画，且极轻 |
| 左侧空区 | **无** | 标题居中，或压在色块左侧 |

浅底四条反转（`IS_LIGHT = true`）：面板白、字幕深字白边、进度条分隔线转深、片尾压向画布底色。

## S2 调色板（一屏最多 4 个色块）

| 角色 | 值 | 用在 |
|---|---|---|
| 电光蓝 | `#2563EB`（亮 `#60A5FA`、深 `#1E40AF`、淡 `#DBEAFE`） | 主色块、序号、当前项 |
| 橙 | `#F97316` | 第二色块、强调、「注意」 |
| 墨黑 | `#111111` | 文字、边框、投影、线条 |
| 米白 | `#FAF9F7` | 反白文字（色块上的字） |
| 灰 | `#6B7280` | 说明字 |
| 浅灰块 | `#E5E2DC` | 未激活项、占位块 |

- **一屏最多 4 个色块**（含文字块）。这是硬上限，跟着 Swiss 海报的密度走。
- 蓝与橙**不同时大面积出现**：一屏里蓝为主时橙只做小面积点（序号、一个小方块），反之亦然。
- 红色 `#DC2626` 与绿色 `#16A34A` 只在「叉 / 勾」语境出现，不做装饰色。
- 墨黑是结构色：所有文字与边线用它，**不用深灰代替**（深灰会让画面变软）。

## S3 字体

- 中文 Noto Sans SC **900**，**不压窄**（`squeeze: 1`）——Swiss 靠字重和留白，不靠变形。
- 数字与英文用 Noto，`numFamily: 'cjk'`（Orbitron 会把极简变成科技片）。
- 最小 **24px**。
- 字距略开（letterSpacing 1–2），大写英文尤其。

## S4 图元语法

核心语法是**「实色块 + 硬投影」**，这是本套唯一的形态语言。

- `shape: {sw: 0, radius: 0, lightMode: 'shadow', fillMode: 'solid'}`：**无描边、无圆角、纯实色填充**。
- 硬投影：`8px 8px 0 #111111`（无模糊、无扩散）。这一条不能改成柔和投影，一柔就变成第 4 套。
- 色块尺寸走 8 的倍数（128 / 256 / 384 / 512 宽），间距 24 或 32，**对齐到 8 的网格**。
- 大序号（01 / 02 / 03）用 900 字重、96–150px，压在色块角落或色块外的留白里。
- 分隔用**粗横线**（6–8px 墨黑实线），不用细线（`sw: 0` 意味着细线本来就不存在）。
- 图标若要，用**实心几何**（圆、方、三角、半圆拼），不要线稿、不要圆角图标。

## S5 光

- **没有光**。没有 glow、没有渐变、没有模糊投影、没有白闪。
- 唯一的「层次」是硬投影的方向与距离——所有元素投影方向必须一致（右下 8px），**投影方向不统一等于光源有两个**。
- 当前重点：`6px 6px 0` 的**彩色硬投影**（蓝或橙），不是彩色光。
- **高光时刻是 `headline` 型**：一整块纯色（蓝或橙）压满画面中部，反白大字一句断言，硬投影推到 12px。不要扫光、不要白闪。
- `GLOW_*` 与 `BLOOM` 在本套全为 `none`。

## S6 覆盖层皮肤

| 项 | 值 |
|---|---|
| HUD 填充 / 字 | `#111111` / `#FAF9F7`（反白胶囊） |
| 进度条已播 / 未播 | `rgba(37,99,235,.55)` / `rgba(17,17,17,.14)` |
| 字幕字 / 描边 | `#111111` / `#FAF9F7` ← 反转，且描边色与画布同色 |
| 章节卡序号 | `#2563EB` |

字幕 44px / top 637 不动。本套字幕**不加粗到 900**（超粗字幕在米白底上会压过画面），保持 700。

## S7 素材：全代码绘制

`useImageGen: false`、`spec: null`。本套的美学是「平面印刷」，任何位图、渐变球、3D 图标都会立刻破坏它。

- 背景就是 S1 的极浅渐变，不叠纹理、不加噪点。
- 所有图形是**几何拼贴**：矩形、圆、半圆、三角。圆只用于「点」，不用于圆角矩形。
- 需要「实物」时用**符号化图形**（手机 = 竖矩形 + 顶部一条线；文档 = 矩形 + 三条横线；人 = 圆 + 半圆），**保持直角**。
- 图形填充只用调色板里的实色，**不允许 opacity 半透**（半透会混出第五种颜色）。

### 出静帧前核对

- 全画面找不到圆角（放大看每个角都是直角）。
- 全画面找不到渐变、模糊、发光：硬投影边缘是锐的。
- 一屏色块 ≤4 个；蓝橙没有同时大面积出现。
- 所有元素投影方向一致（右下）、距离一致（8px，重点 6px/12px）。
- 色块位置落在 8 的网格上，列边对齐。
- 字幕深字浅边，字重 700。

---

## S8 红线

1. **禁止发光、渐变、玻璃**（本套只有实色 + 硬投影）。
2. 禁止圆角与细线描边（`sw` 恒为 0，`radius` 恒为 0）。
3. 禁止一屏超过 4 个色块。
4. 禁止白字压在浅底上（只允许反白，即色块上的字）。
5. 禁止扫光 / 白闪作为高光时刻。
6. 禁止半透明填充与 3D 图标（会混出第五种颜色）。
7. 禁止投影方向不统一（等于有两个光源）。
